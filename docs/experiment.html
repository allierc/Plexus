A spread of simulations

One engine, many living systems — hover a title to read its spec

Codebase operators only. Every clip on this page is produced by a registered core operator run through the Plexus engine — one config/**.yaml spec, no per-simulation code. The interaction and boids laws are ported from ParticleGraph; the slime-mould (Physarum) agent from Sebastian Lague’s Slime-Simulation; the softened self-gravity from Philip Mocz’s Create Your Own N-body Simulation (2020); the continuum solver is MLS-MPM (Hu et al. 2018); and each strange attractor cites its originating paper (Lorenz 1963, Rössler 1976, Sprott 1994, …). Prototype-only experiments have been dropped — the gallery is the live operator vocabulary of the paper.

Each clip below is one spec.yaml over the identical operators and schedule grammar; hover (or tab to) a simulation’s title to read the exact spec that generated it. The first two are validated to floating-point precision against ParticleGraph. Every movie is rendered the same way: a black-background, full-frame point splat, so the dynamics — not the chrome — is what you compare across systems.

How a clip is made

python Plexus_Main.py -o generate_plot <config> runs the forward simulation, writes the trajectory, and renders the movie — no per-simulation code, only the spec differs. e.g. ... -o generate_plot inverse_square/spiral_galaxy_3d or ... -o generate_plot attractors/lorenz.

Interaction & flocking — validated against ParticleGraph

Lateral operators over a radius neighbour graph: a per-type force law (attraction–repulsion) and the three boids rules that sum to flocking.

Stigmergy — Physarum slime

A set + a scalar field, coupled: agents deposit a trail, the field diffuses and decays, agents sense and steer up it — a self-reinforcing transport network.

Continuum mechanics — MLS-MPM

The same particle Level, now a material: the decomposed MLS-MPM cycle (strain → scatter → grid solve → gather) carries elastic, fluid, and granular bodies.

Inverse-square law — self-gravity & electrostatics

One squared_law operator, two regimes: law: gravity (mass, always attract, all-pairs) collapses a disc into a galaxy; law: coulomb (signed charge, like-repel) is a plasma.

Strange attractors — attractor_flow

A single lateral operator rides a whole cloud along a dissipative 3D chaotic flow ẋ = f(x); a tiny seed is stretched-and-folded until the cloud is the attractor. Ten systems ship; four shown.

Differentiable optimization — a foraging colony

Because the whole rollout is differentiable, a design can be optimized, not just simulated. A slime-style foraging colony (the same deposit/diffuse/sense/glide operators) is tuned by a black-box UCB search over its spec parameters — from a hand-set start to the best found. Each strip runs left → right, start → optimized.
