# HYPOTHESES — the previous campaign's claims, held open

Every scientific claim of the 60-batch `prototype/cardio_mpm` campaign is recorded here **as an
open question**, not as knowledge. None of them is inherited as true and none is inherited as
false: they were reached with rulers nobody had checked, on a fit that was never tested against
unseen data, in a program that never fixed its random number generator. Some are probably right.
We will find out which in the ordinary way.

**Nothing in this file may be cited as evidence.** A claim leaves this file only by being
re-tested here, and it moves to `BELIEFS.md` only if it survives.

**Defaults are beliefs.** A setting that was chosen because of a retired conclusion is listed
below with the rest — the fact that it is a number in a file rather than a sentence in a ledger
does not make it earned.

Status vocabulary: `untested` (nothing here has spoken to it) · `re-tested: confirmed` ·
`re-tested: refuted` · `unscoreable` (no certified instrument can decide it yet).

> **H23 carries a warning that is not itself a conclusion of the old campaign.** Giving every
> tracked point an independent random timing offset — destroying coordination entirely — returns a
> *perfect* LoopScore. Until a certified measure exists that can tell a coordinated contraction
> from an incoherent one, every claim above about timing, waves, rotation or torque
> (H06–H09, H13, H17–H19, H22) is **unscoreable**, not merely untested.
