Everything we've done today has been pre-flight. Here's what I've actually verified stands between you and a week-long unattended run, in the order that matters.

Hard blockers — the week fails without these
1. There is no multi-round driver. I grepped for it: no loop, no --rounds, no scheduler anywhere in discovery/. round.py runs one round and exits. "Runs unattended for weeks" is specified in the design document and not implemented. Something has to invoke rounds repeatedly, survive a failed one, and stop on the terminal verdict.

2. A crashed round wedges the loop permanently. pose() raises ValueError: hypothesis {hid} already posed (hypothesis.py:176). The round id is sup.round + 1, and sup.round only advances at the end, via sup.observe(). So a round that dies after posing but before finishing leaves the state at the old round → next attempt uses the same id → same hypothesis ids → raises again → forever. One crash on day 2 costs you the remaining five days. This is the single most dangerous thing in the system for unattended operation, and it is invisible in a one-round test.

3. The loop currently refuses to start. Instrument gate not certified → admission gate closed. That's correct behaviour, but it means launch is blocked until the labelled set is fixed — and ref_uniform_inflation can't be the rank-0 control at any setting (it's either an exploded buffer or a plain sphere). It needs replacing with the cauliflower recipe, then a re-score.

Will silently waste the week
4. GPU utilisation was ~10% on the one measured round — the Proposer blocks for ~7 min with six GPUs idle. Over a week that is the difference between ~100 rounds and ~1000. Barely worth fixing for a test; the top ROI item for a week.

5. No LLM budget ceiling is enforced. run_agent is never called, and the round reported calls: 0 after ~22 real calls. Unbounded spend for seven days.

6. terminal()'s stop verdicts are computed and thrown away — only the ESCALATE prefix is read. The campaign cannot stop on budget or on success; it runs until a human notices.

7. run_id collides across θ variants (params={} at run_one.py:197). A week of parameter sweeps writes a permanently aliased archive.

8. Proximity clustering is degenerate — one cluster, and a second is unreachable by construction. That machinery is the stated antidote to "thirty rounds, four ideas", which is exactly the failure mode a week-long run exists to avoid.
